Reference

This page documents all functions provided by Rfam.jl. None of them are exported, so they must be called with the Rfam. prefix.

Configuration

Rfam.set_rfam_directory — Function
set_rfam_directory(dir)

Sets the directory where Rfam data is downloaded in a LocalPreferences.toml file.

source
Rfam.get_rfam_directory — Function
get_rfam_directory()

Returns the directory used to cache Rfam data.

The value is read from LocalPreferences.toml when available and falls back to the JULIA_RFAM_DIR environment variable.

source
Rfam.set_rfam_version — Function
set_rfam_version(version)

Sets the version of Rfam used in a LocalPreferences.toml file.

source
Rfam.get_rfam_version — Function
get_rfam_version()

Returns the configured Rfam release version.

The value is read from LocalPreferences.toml when available and falls back to the JULIA_RFAM_VERSION environment variable.

source
